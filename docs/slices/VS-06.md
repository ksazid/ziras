# VS-06 — POC Coverage & Extraction Hardening

Status: Approved for implementation

## Objective

Close the validation gaps recorded in `docs/testing/VS-05-MALTA-POC-TEST-REPORT-2026-08-31.md` before any user-facing feed work.

## In scope

1. Split Eden route semantics: `/special-offers` uses promotion extraction and `/whats-on` uses event extraction.
2. Harden browser-source validation so VisitMalta cannot report a healthy run when a rendered page yields no event candidates.
3. Add deterministic browser-rendered event fixture coverage for the VisitMalta acquisition path.
4. Qualify two additional Malta-local source classes for the POC using current public policy evidence and strict source controls.
5. Reach at least five independent POC source classes without weakening source policy.
6. Preserve existing ingestion, freshness, dedupe, provenance and ranking invariants.

## Qualified POC additions

### Spazju Kreattiv Events

- class: `cultural-venue-events`
- acquisition: static
- adapter: event
- approved path: `/events/`
- rate cap: 1 request/hour
- data: factual title/date/location/deep-link metadata only
- attribution required; raw page/image storage prohibited
- robots check required at runtime
- production requires a fresh explicit policy review

Current official listings expose Malta-local September 2026 inventory. No blanket automated-access or non-commercial-use prohibition was located in the reviewed public policy material. This is a POC policy decision only, not production permission.

### Eurosport Malta Sale

- class: `sports-retail`
- acquisition: static
- adapter: promotion
- approved path: `/sale`
- rate cap: 1 request/hour
- data: factual product name/current price/original price/deep-link only
- attribution required; raw page/image storage prohibited
- robots check required at runtime
- no account/cart/login access
- production requires a fresh explicit policy review

The public Sale page currently exposes old/new EUR prices. The reviewed published Terms & Conditions govern sale of goods, and the reviewed Online Offers terms did not contain a blanket automated-access/non-commercial-use prohibition. This is a POC policy decision only.

## Explicitly rejected for POC in this review

- Plaza Shopping Centre — published terms restrict content to personal non-commercial use and restrict copying/storing; not approved.
- University of Malta — published authorized-use wording is noncommercial/personal/educational; not approved without written permission.
- competitor/aggregator inventory such as Cloudigo/shops-style aggregators — partner/licensed route only.

## Out of scope

- production source enablement
- scheduler activation
- release approval
- anti-bot, stealth, proxy rotation or CAPTCHA bypass
- merchant onboarding
- user-facing feed/UI

## Acceptance criteria

- Eden route-specific semantics are configuration-driven, deterministic and tested.
- Longest matching route override wins; no vendor-specific conditional is introduced into the pipeline.
- VisitMalta remains browser fallback only and has a minimum-candidate health gate plus deterministic rendered-event fixture coverage.
- At least five independent POC-approved source classes exist in the catalog after the VS-06 overlay.
- Restricted/ambiguous sources remain research-only, partner-only or denied.
- Kernel, Meta, source-pack, ingestion, VS-06 tests, PostgreSQL/PostGIS/pgvector integration and PES preflight pass on an exact head.
- No production policy, scheduler or production-enable flag changes.

## Validation targets

VS-06 does not claim the PRD 14-day POC gates are passed. After certification/merge, the governed POC ingestion run must still measure discoveries/day, valid-when-opened, stale/expired rate, duplicate rate, source success and browser/static split.
