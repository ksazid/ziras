# VS-06 — POC Coverage & Extraction Hardening

Status: Testing

## Objective

Close the validation gaps recorded by the first VS-05 Malta POC report before any user-facing feed work.

## Approved scope

1. Split Eden route semantics: `/special-offers` uses promotion extraction and `/whats-on` uses event extraction.
2. Harden browser-source validation so VisitMalta cannot report a healthy run when a rendered page yields no event candidates.
3. Add deterministic browser-rendered event fixture coverage for the VisitMalta acquisition path.
4. Add two explicitly approved, low-rate POC source classes after separate SourcePolicy review.
5. Preserve existing ingestion, freshness, dedupe, provenance and ranking invariants.
6. Prepare the five-class source set for a formal `poc` ingestion metrics run.

## Existing-source hardening

### Eden Cinemas

- `/special-offers` → `promotion`
- `/whats-on` → `event`
- route semantics are data-driven via longest matching path prefix.
- no Eden-specific conditional is added to the pipeline.

### VisitMalta Events

- remains browser acquisition.
- `minimum_candidates = 1`.
- a successful render that yields zero normalized events is recorded as `insufficient_candidates`.
- unhealthy zero-candidate results do not populate the ranked feed.

## Configuration boundaries

`malta-source-hardening.json` contains extraction-only metadata:

- `route_adapter_kinds`
- `minimum_candidates`

The certified `malta-source-policy.json` remains the VS-04 baseline. VS-06 adds separately auditable POC permissions through `malta-source-vs06-poc.json`; the loader combines the baseline + approved extension and then applies extraction-only hardening.

Hardening cannot mutate SourcePolicy authority.

## Approved POC source classes

1. `visitmalta_events` — `events-official`
2. `eden_cinemas` — `entertainment-offers`
3. `homemate_offers` — `home-retail`
4. `spazju_kreattiv_events` — `cultural-venue-events`
5. `eurosport_malta_sale` — `sports-retail`

The two VS-06 additions are restricted to one public path each, 1 request/hour, attribution required, and no raw page/image retention. Production access remains unapproved.

## Out of scope

- production source enablement
- scheduler activation
- release approval
- anti-bot, stealth, proxy rotation or CAPTCHA bypass
- merchant onboarding
- user-facing feed/UI

## Acceptance criteria

VS-06 can reach certification readiness when:

- route-aware semantics and source-health checks pass;
- the default catalog contains exactly five explicitly approved POC source classes;
- both new source policies remain POC-only and production-denied;
- all prior discovery-engine regression tests pass;
- PostgreSQL integration passes;
- PES preflight passes;
- no prohibited source is relaxed.

VS-06 certification alone does **not** pass the product POC. Formal ingestion metrics and the PRD 14-day thresholds remain separate validation evidence.
