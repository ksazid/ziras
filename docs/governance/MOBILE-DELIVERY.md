# Mobile Delivery Governance

PES Mobile preserves the shared PES authority and lifecycle while replacing the product web surface with an Expo React Native application.

## Required mobile evidence

- Expo Doctor and dependency compatibility
- TypeScript, lint and unit-test results
- Android/iOS identifiers and runtime-version policy
- device or emulator smoke evidence for affected platforms
- deep-link, notification, offline, accessibility and permission evidence where applicable
- exact certified Git SHA bound to the build
- store metadata/privacy review for store releases
- rollback or forward-recovery plan, including OTA compatibility boundaries

The governance dashboard is static PES infrastructure and is not deployed as the customer product.
